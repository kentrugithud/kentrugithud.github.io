Статистика TikTok(Android)

Написан на: C++ и Java

Программа для просмотра статистики TikTok: сколько видео посмотрел, сколько лайкнул и т.д. Для использования нужно авторизоватся или скачать данные из TikTok: зайти в профиль → три полоски → настройки → конфиденциальность → аккаунт → скачать ваши данные. Запросить данные и подождать 5 часов или сутки, затем скачать ZIP и загрузить в приложение.
